# 他們坐在哪裡？

給國小學生的互動小故事：臺灣一百多年來，身心障礙的同學怎麼從「被分開上學」，一步一步走到「和大家坐在同一間教室」。

## 這個程式的目標

看完這個故事，希望學生可以：

1. **看懂一百多年的改變**：知道身心障礙的同學，怎麼從「被分開上學」走到「和大家坐在同一間教室」。
2. **說出尊重的話**：明白叫法為什麼一直改，學會把「人」放在前面。
3. **換一個角度想**：了解讓人不方便的，常常是沒做好的環境，不是那個人。
4. **看看自己的學校**：找找哪裡對每個同學還不夠友善，想想可以怎麼改。
5. **和 AI 小幫手一起討論**：每個年代的「想一想」，都可以和小燈聊。說出自己的想法，小燈會先找出想得好的地方，再問一個小問題，陪學生想得更深。

## 內容

- 封面與學習目標
- 四個年代：一百多年前（1891–1961）、阿公阿嬤小時候（1962–1983）、爸爸媽媽小時候（1984–1996）、現在（1997 年到今天）
- 每個年代有圖、當時的叫法、當時的想法、可點開的事件故事，以及「想一想」討論題
- 四個年代共用同一張圖：翻頁時，小孩會從上一個年代的位置走到新的位置
- 「一起看」：把四個年代排在一起比較（坐在哪裡、怎麼叫、怎麼想）
- 四題小考驗

寬螢幕（電腦、橫放的平板）是一個畫面：左邊故事、右邊小燈，不用捲動，字的大小會跟著螢幕調整。窄螢幕（手機、直放的平板）改成上下排列。

## AI 小幫手「小燈」

小燈出現在每個年代的「想一想」裡，是陪學生討論的 AI agent：

- 沒有標準答案，不說學生對或錯；先用學生自己的話回應，再問一個追問，讓學生自己把想法說出來，小燈不先講答案。
- 每一題有自己的討論方向和追問方向（寫在 `index.html` 每個年代的 `aim`、`probes`）。
- 學生卡住時，提供「我不知道怎麼想」、「給我一點提示」、「幫我整理我的想法」按鈕。
- 學生認真回答三次後，小燈會幫他整理自己說過的想法，並提醒可以繼續看故事。
- 學生問詞語或故事裡的事：先查「詞語小字典」和故事內容；沒有寫的，請他問老師，不自己編。
- 學生說出取笑或排斥的話：不罵他、不附和，請他換個角度想。
- 學生說到自己被欺負或很難過：先接住他的感受，請他告訴信任的大人（老師、輔導老師或家人）。
- 不判斷任何人是不是身心障礙、是不是生病；不詢問個人資料，學生自己說出來時會提醒他不用說。
- 每一句回覆大約兩、三句話，顯示前會先去掉多餘的符號和空行。

小燈的說明書用模擬的學生對話實際測試過七輪（最完整的一輪是 36 段對話、80 句），依結果修改。

小燈有兩種運作方式：

- **在 claude.ai 上開啟**：使用 Claude Artifact 的 `sample` 功能，用開啟者自己的 Claude 額度。
- **在 GitHub Pages 上開啟**：透過 `worker.js`（Cloudflare Worker）呼叫 Claude API（Claude Haiku 4.5）。API 金鑰只存在 Cloudflare，不會出現在網頁或 GitHub 上。

如果兩者都沒有設定，小燈會自動隱藏，故事、圖片和小考驗都可以照常使用。

## 設定小燈的後端（Cloudflare Worker）

1. 在 [Claude Console](https://platform.claude.com) 購買 API 額度，並建立一把 API 金鑰。
2. 到 [Cloudflare](https://dash.cloudflare.com) 註冊免費帳號，進入 **Workers & Pages → Create → Create Worker**，取名 `where-they-sit-ai`，按 **Deploy**。
3. 按 **Edit code**，把 `worker.js` 的全部內容貼上，取代原本的程式，按 **Deploy**。
4. 回到 Worker 頁面，進入 **Settings → Variables and Secrets → Add**，類型選 **Secret**，名稱填 `ANTHROPIC_API_KEY`，值貼上你的 API 金鑰，儲存。
5. 複製 Worker 的網址（像 `https://where-they-sit-ai.你的帳號.workers.dev`），貼到 `index.html` 裡的 `var AI_ENDPOINT` 引號中間（目前已設定好）。
6. 確認 `worker.js` 裡的 `ALLOWED_ORIGINS` 是你的 GitHub Pages 網址（預設是 `https://chiaying1230.github.io`）。

保護措施：Worker 只接受來自你網站的請求、限制每則訊息長度和回答長度，小燈的說明書也放在後端，別人無法把它當成一般聊天機器人使用。建議在 Claude Console 不要開自動儲值，額度用完就會自動停止。

## 蒐集對話資料（Google 試算表）

每次學生和小燈對話，後端會在試算表新增一列：時間、學生代號、年代、第幾輪、學生寫的話、小燈的回答。

- 學生代號是每次打開頁面時隨機產生的 6 個字（例如 `K7Q3XA`），不記錄名字或任何個人資料。同一位學生重新打開頁面會拿到新代號。
- 頁面上會告訴學生：對話會被老師看到，用來改進教學。

設定方式：

1. 建立一個新的 Google 試算表，取名「他們坐在哪裡 對話紀錄」。
2. 按「擴充功能 → Apps Script」，把 `apps-script.gs` 的全部內容貼上，取代原本的程式，按儲存。
3. 上方函式選單選 `setup`，按「執行」，依畫面授權。試算表會出現「對話紀錄」分頁和一列測試資料。
4. 按「部署 → 新增部署作業」，類型選「網頁應用程式」，執行身分選「我」，存取權選「所有人」，按部署，複製「網頁應用程式網址」。
5. 到 Cloudflare 的 Worker → Settings → Variables and Secrets，新增 Secret：名稱 `SHEET_URL`，值貼上剛剛的網址。

網頁應用程式網址只放在 Cloudflare 的秘密變數裡，不要公開，否則別人可以寫入假資料。

## 修改故事或小燈的說明書之後

故事內容和小燈的說明書在 `index.html` 和 `worker.js` 各有一份，兩邊要一樣。改了其中一邊的文字，另一邊也要改，然後：

1. 把新的 `index.html` 和 `worker.js` 放上 GitHub。
2. 到 Cloudflare 的 Worker 按 **Edit code**，把新的 `worker.js` 全部貼上、取代原本的程式，按 **Deploy**。沒有做這一步，GitHub Pages 上的小燈還是會用舊的故事和舊的說明書。

`ANTHROPIC_API_KEY` 和 `SHEET_URL` 兩個秘密變數不用重設。

## 使用方式

用瀏覽器打開 `index.html` 即可，不需要安裝任何東西。
